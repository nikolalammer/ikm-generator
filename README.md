# iKM Arbeitsblatt-Generator

Stellt aus Bausteinen Übungsblätter zur iKM PLUS Deutsch (Lesen, 7. und 8. Schulstufe) zusammen. Das Ergebnis lässt sich als Word-Datei speichern und dort bearbeiten. Schwarzweiß, Schrift mindestens 11 pt.

Enthalten: 14 Lesetexte mit Aufgaben (SK 1 bis 4) und Lösungen, Merkkästen zu Teststrategien, Satzlesen, Lautlese-Tandem und Vorlagen für eigene Texte.

Die Seite läuft komplett im Browser. Es werden keine Daten gesendet oder gespeichert.
